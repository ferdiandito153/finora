# FINORA

Personal finance dashboard built with React, Vite, Tailwind CSS v4, Recharts, and Lucide React.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## GitHub Pages
This repository is configured for a GitHub repository named `finora` (lowercase).
The Vite base path is `/finora/`. The GitHub Actions workflow builds the app and publishes `dist/`.

If you choose a different repository name, update `base` in `vite.config.js` to `/<repository-name>/`.

Demo dashboard data is illustrative and stored locally in `src/App.jsx`. No personal financial data is connected.
